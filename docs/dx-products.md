expose a CLI route.

| --- | --- | --- | --- |
| `code` | `essence-dx/code` | DX Code editor (Zed fork) | `dx desktop sync-web` |
| `tui` | `essence-dx/tui` | DX-TUI terminal UI | hidden `dx tui` |

| `website` | `essence-dx/website` | official dx website | `dx site` (hidden) |
